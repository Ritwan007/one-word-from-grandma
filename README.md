Entry for the [One Word From Grandma](https://make.fun/competitions/u-0xkianno-one-word-from-grandma-f04bed16) competition on [make.fun](https://make.fun).

The program writes exactly one word to `/output/entry.txt` — the single word
grandma would text about AI:

> **computery**

Warm, slightly baffled, and instantly readable: the word a real grandmother
types when the grandkids show her the new computer thing.

## Run

```sh
node main.ts
cat /output/entry.txt
```

Node 22+, standard library only, no network.
